# 浮生录

人生模拟器合集。选一个背景，投一次胎，从出生活到离世。玩法借鉴 *1 in 8 Billion*，同一套引擎，不同的世界。

| 游戏 | 目录 | 说明 |
|---|---|---|
| 十四亿分之一 | `1in1.4b/` | 按真实人口比例随机投胎到中国某个省市、某种家庭，2026 年出生，过完普通人的一生 |
| 江湖一梦 | `jianghuyimeng/` | 射雕三部曲放进同一个江湖，重生成书中人物，改写原著里的命运 |

- 试玩：用浏览器打开根目录的 `index.html`（大厅），或者直接打开某个游戏目录里的 `index.html`。不需要服务器，存档在浏览器里。
- 部署：纯静态网站。`node share/tools/build.js` 打包到 `dist/`，阿里云、Cloudflare 的做法见 `docs/DEPLOY.md`。
- 开发：先读 `CLAUDE.md`（给开发者和 AI 助手的说明），写剧情前读各游戏的 `docs/SPEC.md`。
- 改完数据在根目录跑 `node share/tools/simulate.js <游戏目录> 40`，必须输出“没有发现问题”。
