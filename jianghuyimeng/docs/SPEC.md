# 江湖一梦 · 内容规范

射雕三部曲（射雕英雄传、神雕侠侣、倚天屠龙记）混在同一条时间线上。玩家重生成一个有名有姓的人物，从出生（或者从当前江湖年份中途醒来）活到命终，一局约 30 分钟。剧情文字全部预先写好，不调用 AI。

## 两条铁律（自圆其说靠这两条）

1. **大势不可改**：朝代更替、蒙古南下、襄阳城破、元亡明兴，任何选择都改不了。改的是个人生死、谁拿着什么、谁和谁在一起。
2. **剧情不写死人名，写条件**：引用别的人物时先 `g.alive('id')`；用 `g.f('flag')` 读其他人物的改命结果，写出变体文字。原定的人不在了，就让合适的人顶上（槽位 `g.slot('丐帮帮主')` 等），或者让事件换一个合理的发生方式。例：杨过如果带走了玄铁剑（`yangKeepsSword`），倚天剑、屠龙刀照样存在，只是改由郭襄在峨嵋用这块玄铁铸成。

## 人物格式

```js
{
  id: 'guojing', name: '郭靖', py: 'GUO<<JING', book: '射雕英雄传', sex: '男', born: 1,
  origin: '一句话出身（同代人列表里用）',
  birthplace: '蒙古草原', home: 'grassland',          // home 必须是 JY.LOCS 的键
  bg: 2,                                                // 出身 1–5，五个点
  info: { 门派: '无', 身份: '牧民之子' },               // 名帖上的字段，剧情里用 g.info 改
  look: { hair: 'topknot', hairColor: '#2a1d14', robe: '#7a5236', accent: '#c9a45c' },
  //   hair: topknot（发髻）| bun（女子发髻）| twinbun（双髻）| long（披发）| bald（光头）| cap（帽子）| braid（辫子）
  family: [ { rel: '母亲', id: 'liping' }, { rel: '父亲', name: '郭啸天', note: '纪年 0 年死于牛家村' } ],
  fateText: '原著命数：一两句话写这个人原著里的结局',
  st: [根骨, 悟性, 心境, 情义, 武学, 声望, 正邪],       // 出生时的属性，0–100，正邪 -100–100
  death: (g) => g.f('guoSurvive') ? { y: 92, cause: '在终南山下寿终', mod: true } : { y: 71, cause: '襄阳城破，与黄蓉一同殉城' },
  exists: (g) => true,                                  // 可选：别人的改命让这个人根本不会出生时返回 false
  ms: [ [1, '生于蒙古草原'], [18, '南下中原', (g) => !g.f('jingStayMongol')] ],  // 当 NPC 时显示的近况
  arc: {                                                // 只有可玩人物才有 arc
    focus: '闭关练功',                                  // 默认年度重心
    intro: '出生时写在生平第一行的话（第二人称）',
    lastWords: '原著风格的一句遗言',
    req: (g) => true,                                   // 可选：能不能重生成这个人
    pauses: [],                                         // 可选：专属人生关口，格式同 JY.PAUSES
    nodes: [ ... ],
  },
}
```

- 不可玩的配角省略 `arc`、`look`、`py`、`st`、`home`、`fateText`。`minor: true` 的配角死时不写进江湖大事记。
- `death` 返回的 `cause` 是一个独立短语，前面会接“某某，”。被别人的选择改掉的死法加 `mod: true`。
- `ms` 要覆盖从出生到死亡，给同代人面板用。

## 节点格式

```js
{ id: 'gj_zhangjiakou', age: 18,   // 或者 y: 18（绝对纪年），两者择一
  t: '张家口', loc: 'zhangjiakou', // loc 可选：节点触发时把人物移到这里，场景图随之变化
  cond: (g) => !g.f('jingStayMongol'),
  text: '一两到四句，第二人称“你”。可以是函数 (g) => ...',
  choices: [
    { t: '请他吃饭，再送他貂裘和小红马', canon: true,
      fx: (g) => { g.stat('情义', 8); g.rel('知己', 'huangrong'); }, res: '小叫化洗干净了脸，是个姑娘。' },
    { t: '付了钱就走', dev: 40,
      fx: (g) => { g.set('jingrongApart'); }, res: '你没再见过那个小叫化。' },
    { t: '跟他比划比划', check: ['武学', 40], dev: 10,
      fx: ..., res: ...,
      fail: { fx: ..., res: ..., dev: 0 } },
  ] }
```

- 自动节点：`auto: true`，没有 `choices`，有 `text` 和可选的 `fx`。用来写不需要选择的原著大事和童年经历。
- `canon: true` 是原著走向。非原著选项必须写 `dev`（改命度，10–50；越大越偏离原著）。
- `check: ['悟性', 65]` 成功率 = 50 + (属性 − 65) × 3，夹在 5%–95%。`['悟性', 60, 'low']` 表示属性越低越容易成功（比如左右互搏）。
- 会让玩家死掉的选项：`fatal: true`，`fx` 里调用 `g.die('死法短语')`。
- 每个可玩人物的每个抉择节点至少有一个原著选项（玩家已经改过命导致原著选项不成立时除外），至少一个改命选项。
- **选项数按情节定，2–4 个**：真正的两难就 2 个，多数 3 个，局面复杂才 4 个。不要为了凑数加结果差不多的选项。带 `cond` 的选项在任何状态下可见数都要在 2–4。
- **每个抉择至少 2 个选项要有后果，而且后面读得到**（见下面“后果”一节）。`simulate.js` 会检查，`consequence.js` 能列出每个选项的后果类型。

## g 接口

| 调用 | 作用 |
|---|---|
| `g.Y` / `g.age` / `g.me` / `g.loc` | 当前纪年、年龄、玩家人物 id、所在地点 |
| `g.s('武学')` | 读玩家属性 |
| `g.stat('武学', +10)` | 改玩家属性（自动夹在范围内） |
| `g.f('flag')` / `g.set('flag')` | 读、写改命标记（跨世保存）。新标记要用 `JY.addFlags({ flag: '一句说明' })` 注册，说明会出现在结局的“江湖因你而变” |
| `g.remember('key', 值)` / `g.recall('key')` / `g.since('key')` | 这一世的记忆：只在当前这一世有效。`recall` 返回记下的值，`since` 返回过了几年（没记过是 -1）。用于“这一世后面读到”的后果，例如通用奇遇几年后的回响 |
| `g.alive('id')` / `g.exists('id')` / `g.ageOf('id')` | 某人是否活着、是否存在、几岁 |
| `g.kill('id', '死法', canon)` | 杀死某个 NPC；`canon` 为 true 时不算改命 |
| `g.die('死法')` | 玩家死亡 |
| `g.move('loc')` | 玩家移居。场景图和名帖“现居”会跟着变 |
| `g.info('门派', '全真教')` | 改名帖字段：门派、身份、师承、志向…… |
| `g.rel('师父', 'hongqigong')` / `g.unrel('师父')` | 家人与师承面板。第二个参数是人物 id 或纯文字名字 |
| `g.knows('id')` | 此刻这个人是“我”的什么人（返回称呼，如“外公”“师父”），不认识返回 `''`。先看这一世 `g.rel` 记下的，再看原著关系网 `data/relations.js` |
| `g.party(['huangrong'])` | 场景图里站在玩家身边的人（最多 3 个） |
| `g.slot('丐帮帮主')` | 槽位：`至尊`、`丐帮帮主`、`襄阳守将`、`南帝` |
| `g.log('文字')` / `g.chron('文字', mod)` | 额外写一行生平 / 江湖大事记 |
| `g.name('id')` / `g.isMe('id')` / `g.rnd()` | 工具 |

## 后果：选了什么，后面要读得到

用户要求：每个选择都要在一定程度上影响后面的剧情。一个选项算“有后果”，满足任一条：

- 设改命标记 `g.set('x')`，而别处有 `g.f('x')` 读它：同一世后面的节点文字变体、选项的 `cond`、新的条件节点、某人的 `death`/`ms`，或者下一世别的人物的节点、世界事件、奇遇条件。跨世、跨人物的后果用这个。
- 记下这一世的记忆 `g.remember('x', 值)`，而后面有 `g.recall('x')` / `g.since('x')` 读它。只在这一世有意义的后果用这个（例如通用奇遇）。
- 杀人、自己死、改师承家人、门派身份、去处（`g.kill / g.die / g.rel / g.unrel / g.info / g.move`）。

只改属性（`g.stat`）算轻后果：影响以后的成功率，剧情文字不变，不算数。

写法要点：

- 每个可玩人物至少 3 处**真正的分叉**：选了改命选项，后面出现不同的节点（`cond: (g) => g.f('x')`），原著节点被替代或改写，而不只是改一句文字。
- 读标记、记忆时，要写成字面的 `g.f('名字')`、`g.recall('名字')`，检查工具靠这个认出来。不要把名字放进变量再读。
- 不能有“设了没人读”的标记，`simulate.js` 会报。
- `res` 要让玩家感觉到后果会留下来（“他记下了你的名字”），后面真的有节点兑现。
- 回响写法见 `data/world.js` 的 `echo(...)`：自动节点（`auto: true, always: true`），条件是 `g.recall(...)` 有值且 `g.since(...)` 过了几年，按当年的选择写不同的文字和效果。

检查：

```bash
node share/tools/consequence.js jianghuyimeng guojing --list   # 列出郭靖每个选项的后果类型
node share/tools/consequence.js jianghuyimeng shendiao         # 只看神雕文件的汇总
```

`--list` 里 `flag / life / state` 算有后果，`stat / none / dead`（设了没人读）不算。

## 人物关系网

`data/relations.js` 按原著记下人物之间的关系：`{ a, b, ab, ba, y, cond, panel }`。`ab` 是 b 对 a 而言的称呼，`y` 是相识（或关系成立）的江湖纪年，`cond` 是改命让关系不成立的条件，`panel: true` 的会自动显示在“家人与师承”。同一对人可以有多条，按年份递进。

- 写任何提到别人的剧情，都用 `g.knows` 判断熟不熟，称呼照它返回的写。
- 奇遇里出现 NPC：熟人写重逢版本，或在 `cond` 里排除熟人。只在不认识时 `g.rel` 结识，免得把“外公”这类原著关系覆盖掉。
- `node share/tools/simulate.js jianghuyimeng 40` 会报“熟人写成陌生人”；`node share/tools/relations.js jianghuyimeng` 是静态的辅助检查，会有误报。

## 世界事件

```js
JY.addEvents([
  { y: 19, who: ['guojing', 'huangrong'], cond: (g) => !g.f('jingrongApart'),
    t: '黄蓉在铁掌峰中了裘千仞一掌，郭靖背她上山求一灯大师救治。', mod: false, fx: (g) => {} },
]);
```

- 世界事件是“江湖传闻”，玩家不在场也会发生，写进大事记，也出现在玩家生平里。
- `who` 写“这件事的主角”。玩家正是这个人时，这条事件跳过（玩家自己的节点会讲）。
- 被改命标记改变了内容的事件，`mod` 写成函数返回 true。

## 奇遇

格式同节点，再加 `y: [起, 止]`、`minAge`、`maxAge`、`cond`。`id` 以 `e_` 开头。`once: true` 表示整个江湖只发生一次；`always: true` 表示条件满足就必定触发（不抽签）。奇遇是混搭的主要来源：不同书的人物在年代重叠时相遇。

通用奇遇（`data/world.js`）任何人物都会碰上，它们的选择用 `g.remember` 记在这一世，几年后由对应的回响奇遇（`e_echo_*`）兑现。新增通用奇遇时，同时写好它的回响。

防止每一世都碰到同一批事（引擎从符合条件的奇遇里均匀抽一个）：

- 新的通用奇遇放 `data/encounters.js`，一定要写 `cond` 收窄：年代（`y`）、地方（`at(g, 'south')` 等地区）、门派、武学或正邪门槛、男女、年纪。不要再写全年代、全地方、只限年龄的奇遇，它们会挤掉别的。
- 古墓、海岛、冰火岛、昆仑山谷里不发生集市上的事（`outside` / `inTown`）。
- 文中的细节（来人、地名、兵器）用 `pk(g, '键', [...])` 随机，同一世里第一次定下后不变，回响里读到同一个。
- 贵人（全真道人、陆乘风、冯默风、胡青牛、五散人、少年朱元璋等）都按原著年代和关系出场：认识的人用 `g.knows` 排除或写熟人版本。

## 人生关口

`JY.PAUSES`（15、30、50、70 岁）和人物专属的 `arc.pauses`。格式同抉择节点，另有 `ask`：一句短问题，显示在墓志页的“人生关口”里（`text` 可以很长，可以是函数）。关口的答案写进名帖（`g.info('志向', ...)`），并用 `g.remember` 记下，下一个关口的 `text` 接着问（三十岁时回头看十五岁的志向）。

## 闲笔

`JY.addFlavor(key, [...])`，key 可以是 `loc:地点`、`char:人物id`、`book:书名`、`focus:重心名`、`age:child|young|adult|old`、`any`。元素可以是字符串、函数，或 `{ t, minAge, maxAge, sex, cond, fx }`。没有大事的年份里每年抽 1–2 句，同一世不重复。

## 写作要求

- 中文，第二人称“你”。每段 1–4 句，短句，白描。不要用“——”插入语，不要“不是……而是……”。
- 贴原著，人名、地名、武功、关系不能错。不要整段照抄原著原文，名句可以化用（“侠之大者，为国为民”）。
- 强奸、虐杀之类不写细节。尹志平之事不写。死亡一句话带过。
- 改命选项要有后果，而且后果要能被后面的节点、别的人物、下一世读到。
- 每个可玩人物：每条路线上节点 25–40 个（抉择至少 14 个）。有多条互斥成长路线的人物（如杨过：古墓、全真、郭靖带大、留在嘉兴）总数可以更多，从出生到原著结局之后都要有内容，覆盖童年。专属闲笔至少 20 句（`char:id`，用 minAge/maxAge 分年龄段）。
- 每本书：本书出现的地点各写 6 句以上闲笔；本书世界事件 15 条以上；本书奇遇 12 个以上（至少一半是跨书混搭的相遇）。
- 写完必须在仓库根目录跑 `node share/tools/simulate.js jianghuyimeng 40`，问题清零，每个抉择节点都被触发过（只能靠前世标记触发的节点除外）。

## v1.4：醒来年纪、练功、寿命、晚年

**醒来年纪**：`game.js` 的 `wakeAge: 10`。首页默认从 10 岁醒来（`E.startLife(id, { fromAge: 10 })`），之前的节点按原著结算，醒来页列出“醒来之前的你”（每个跳过的节点：年纪、标题、原著选项、结果的第一句）。首页勾“从出生开始”就从出生玩。醒来年纪不晚于本人最后一个原著节点和原定死期。`simulate.js` 不带参数调用，仍从出生跑。所以 10 岁以前的抉择照样要写好，玩家可以选从出生开始。

**练功**（`data/world.js` 的 `JY.CULTIVATE`，由 `game.js` 的 `engine.yearEnd` 每年末调用）。不加新属性，都记在这一世的记忆里：

| 键 | 含义 |
|---|---|
| `ng` | 内功深浅 0–100。按年度重心长，越深越难长；武学猛涨时慢慢跟上 |
| `ngT` | 已到的内功境界：未入门、入门、小成、大成、精纯、返璞归真。升一档写一行生平，武学 +1 |
| `ns` | 内伤 0–3：旧伤、内伤未愈、经脉受损。每年耗根骨；“养伤修心”能慢慢化开 |
| `zhm` | 走过一次火（走火入魔那年的纪年） |

名帖上显示“内功”“内伤”两栏。剧情里可以读 `g.recall('ng')`、`g.recall('ns')`。

年度重心的练功强度：

- `稳扎稳打`：武学慢，内功稳，没有风险，五十岁以后多还一点根骨。
- `闭关练功`（苦练）：武学、内功快；每年约 4% 练伤（根骨 −2），心境低于 40 时偶尔内伤。
- `冒进求成`：武学最快；每年约 2–7% 内伤（心境越差越高），约 0.5–1.5% 走火入魔。走火入魔：根骨差或旧伤重的人一半当场死（死法“走火入魔”），其余经脉受损、武学大跌。

**寿命**：`engine.lifespan.base` 从 58 提到 62。五十岁以后每年衰老 1 点根骨（68 岁起 2 点）；内功深的人每年还回 `(ng − 30) / 70` 点（稳扎稳打、养伤修心再加 0.2），最多抵掉六成；每级内伤再减 0.4。`engine.hookDeathFirst: true`：钩子里定的死法不被“寿终”覆盖。

**晚年**（`data/encounters.js` 末尾，`late(...)` 包起来的 `e_late_*`）：45 岁以后人人会碰上，一件之后隔两三年才来下一件，本人这一年有原著抉择时不来。

| id | 条件 | 记忆 | 回响 |
|---|---|---|---|
| `e_late_pupil` 传艺 | 武学 50 | `lt_pupil` all/half/heart | `e_echo_lt_pupil` |
| `e_late_sect` 长老 | 大门派、声望 40 | `lt_sect` seat/lost/yield/young | `e_echo_lt_sect` |
| `e_late_hall` 门户 | 小门派或无门派、武学 55、声望 30 | `lt_hall` open/no/kids | `e_echo_lt_hall` |
| `e_late_lunjian` 论剑 | 武学 70、声望 40，避开华山论剑那几年 | `lt_lj` won/lost/watch/skip | `e_echo_lt_lj` |
| `e_late_guan` 闭关 | 武学 60 | `lt_guan` out/hurt/short/no；成功加 `ng`，失败加 `ns` | `e_echo_lt_guan` |
| `e_late_book` 著书 | 50 岁、武学 60、悟性 45 | `lt_book` book/burn/oral | `e_echo_lt_book` |
| `e_late_retire` 归隐 | 55 岁、原著剧情走完 | `lt_ret` hide/home/stay | `e_echo_lt_ret` |
| `e_late_heir` 传人 | 62 岁、原著剧情走完；读 `lt_pupil` | `lt_heir` pupil/boy/none/friend | `e_echo_lt_heir` |

晚年的事不写原著人物的名字，不抢原著的掌门、帮主之位（只写“执法长老”“自开门户”）。新加晚年事件就用 `late({...})` 包起来，自动排进轮换。
